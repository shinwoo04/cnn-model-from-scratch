# CNN-Architectures-from-Scratch
A collection of popular Convolutional Neural Network (CNN) models implemented from scratch. 
This project follows the evolution of deep learning architectures, starting from VGGnet

## 🚀 Implemented Models
| Model | Notebook | Key Concepts |
| :--- | :--- | :--- |
| **VGGNet** | `VGGnet.ipynb` | Use of small $3 \times 3$ filters, increased depth. |
| **Inception v1 (GoogLeNet)** | `Inception_v1.ipynb` | Introduction of Inception modules and global average pooling. |
| **Inception v3** | `Inception_v3.ipynb` | Factorization of convolutions, improved regularization. |
| **ResNet** | `ResNet.ipynb` | Residual learning & skip connections for training deep networks. |
